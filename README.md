# الألفية للموارد البشرية

نظام موارد بشرية داخلي لـ **شركة الألفية للخدمات الضريبية والمحاسبية**: الحضور من جهاز البصمة، والوقت الإضافي حسب قانون العمل الأردني، والإجازات، والرواتب، ومتابعة مهام العملاء.

**رابط التطبيق:** https://barhoom98.github.io/idarat-al-mawarid-al-bashariya/

## التثبيت على الهاتف

- **آيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **أندرويد:** افتح الرابط في Chrome ← القائمة ⋮ ← «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- **اللابتوب:** افتح الرابط في Chrome أو Edge ← أيقونة التثبيت في شريط العنوان.

الدخول بالبريد الإلكتروني وكلمة السر. غيّر كلمة السر المؤقتة من **الإعدادات ← حسابي**.

## الأقسام

| القسم | ماذا يفعل |
|---|---|
| لوحة المتابعة | من حضر ومن تأخر ومن غاب اليوم، وطلبات الإجازة المعلّقة، والمهام المتأخرة، والبصمات الناقصة |
| الحضور والانصراف | عرض يومي وتقرير شهري، وتصحيح يدوي، واستيراد ملف البصمة |
| الإجازات | رصيد 14 يوماً (21 بعد 5 سنوات)، ومرضية 14 يوماً، وموافقة ورفض |
| الرواتب | إضافي 125% و150%، والضمان الاجتماعي 7.5% و14.25%، وكشف راتب لكل موظف، واعتماد الشهر |
| المهام والعملاء | ملفات العملاء، ومواعيد الإقرارات، والمهام المتكررة |
| الإعدادات | الدوام، والسماح، ونسب الإضافي والضمان، والعطل الرسمية، وربط البصمة، والنسخ الاحتياطي |

الدوام الافتراضي: السبت–الأربعاء 8:30 ص – 5:30 م، والخميس حتى 2:30 م، والجمعة عطلة. يمكن تعديله من الإعدادات.

## ربط جهاز البصمة

راجع [`bridge/README.md`](bridge/README.md).

## البنية

- `index.html` — التطبيق كاملاً (صفحة واحدة، بدون بناء).
- `config.js` — عنوان قاعدة البيانات والمفتاح العام.
- `manifest.webmanifest`، `sw.js`، `icons/` — تثبيت التطبيق على الهاتف والعمل كتطبيق.
- `supabase/` — جداول قاعدة البيانات ودالة استقبال البصمات.
- `bridge/` — برنامج كمبيوتر المكتب لربط جهاز البصمة.

البيانات محفوظة في مشروع Supabase باسم `millennium-hr`، وكل الجداول محمية: لا يقرأ أو يكتب إلا البريد المسجّل في جدول `app_admins` بعد تسجيل الدخول.
